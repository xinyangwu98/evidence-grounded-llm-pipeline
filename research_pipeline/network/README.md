# Network Measurement

This module documents the public structure of the industry narrative network pipeline.

## Workflow

1. Normalize extracted industry labels from local government reports.
2. Build city-year industry co-occurrence records.
3. Construct a PPMI-weighted co-occurrence network.
4. Detect robust narrative communities.
5. Compute city-year narrative measures.
6. Visualize communities, transitions, and spatial distributions.

## Measures

- narrative community
- dominant community
- dominant-community share
- narrative entropy
- transition matrix across Five-Year Plan periods

## Public Outputs

The public repository includes selected aggregate figures for the co-occurrence network, community transition matrix, and spatial distribution of dominant narratives.
