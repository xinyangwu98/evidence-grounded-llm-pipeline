# Econometric Evaluation

This module documents how text-derived indicators are evaluated downstream.

## Workflow

1. Merge firm, city, policy, industry, and text-derived narrative indicators into panel data.
2. Estimate baseline relationships between policy/narrative measures and firm digital transformation.
3. Evaluate mechanisms and heterogeneity.
4. Run robustness checks, including alternative samples and spatially aware standard errors.
5. Export main tables, appendix tables, maps, and audit summaries.

## Public Boundary

The public repository does not release licensed empirical datasets, complete regression tables, or unpublished case-level outputs. It documents the workflow and shows selected aggregate research figures.
